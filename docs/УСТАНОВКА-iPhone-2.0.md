# Установка mwave 2.0.0 на iPhone

Итоговый IPA разработчик кладёт в `C:\Users\Пользователь\Desktop\mwave iPhone\`, рядом со старыми файлами. Точный файл и SHA-256 указаны в отчёте 2.0.

## Скачать самостоятельно

1. Открыть https://github.com/seltain/mwave-mobile/actions и успешный запуск Build iPhone IPA на ветке iphone-2.0.
2. Внизу Artifacts скачать `mwave-2.0.0-ipa-N`. Для скачивания может понадобиться вход GitHub.
3. Распаковать ZIP. Внутри `mwave-unsigned.ipa` и отчёты проверки. Сам IPA распаковывать для установки не нужно.

## Поставить через Sideloadly

1. Подключить разблокированный iPhone кабелем и подтвердить доверие компьютеру. Запустить Sideloadly.
2. Выбрать iPhone и перетащить IPA в окно. Ввести свой Apple ID в Sideloadly, нажать Start; пароль и 2FA вводятся владельцем там же.
3. Для обновления использовать тот же Apple ID и bundle app.mwave.mobile. Устанавливать поверх, не удаляя старое приложение, чтобы сохранить его контейнер и пробный профиль.
4. Если iOS попросит, включить Developer Mode в Настройки -> Конфиденциальность и безопасность, затем перезапустить iPhone. Подтвердить доверие профилю своего Apple ID в Настройки -> Основные -> VPN и управление устройством.
5. Открыть mwave, войти в аккаунт mwave. Для нового аккаунта нужен код приглашения администратора; общий ключ музыкального сервера больше вводить не надо.
6. Если есть данные только в пробной версии телефона: Медиатека -> Аккаунт -> Перенести пробный профиль. Подтвердить, дождаться результата и синхронизации. Перед переносом создаётся копия базы, старый mwave.db не меняется.

Чтобы увидеть медиатеку ПК, его профиль должен быть связан с тем же аккаунтом через мастер ПК 2.0. Если он пока локальный, владелец сначала переносит его этим мастером. В телефонной задаче настоящий профиль ПК автоматически не переносился.

С бесплатным Apple ID приложение нужно переподписывать раз в 7 дней. Повторить установку поверх через Sideloadly тем же Apple ID. Не удалять приложение для обычного обновления/переподписи. Установка именно этой версии на физический iPhone и сохранение данных после переподписи входят в приёмку владельца.

## Проверить после установки

- Любимые/плейлисты/альбомы ПК видны после синхронизации. Порядок совпадает, изменения телефона приходят на ПК.
- Плейлист играет с выключенным экраном, следующая песня запускается сама.
- Экран блокировки и Пункт управления: следующая, предыдущая, пауза, пуск, перемотка, обложка/название/время.
- Кнопки наушников/AirPods, возврат после звонка, переход Wi-Fi/LTE.
- SoundCloud повторно после добавления в любимые. Замерить старт первой и подготовленной следующей песни.
- Без сети медиатека открывается и изменения сохраняются; после сети догоняют ПК. Скачивание аудио ещё не реализовано.
- Вход сохраняется после перезапуска; аккаунты имеют раздельные медиатеки.

Полный список и технические ограничения: [отчёт](ОТЧЕТ-iPhone-2.0.md). Веб-превью/симулятор не подтверждают физические команды и фоновую политику iOS.
