# Как поставить mwave на iPhone

Приложение собирается на GitHub без подписи (файл `mwave-unsigned.ipa`). Подпись делает Sideloadly
на компьютере с бесплатным Apple ID. Ключ сервера в приложение не вшит: его вводят один раз при первом запуске.

## 1. Скачать IPA

1. Открыть https://github.com/seltain/mwave-mobile/actions/workflows/build-ios.yml
2. Выбрать последний зелёный запуск (или нажать «Run workflow», сборка идёт около 30 минут).
3. Внизу страницы запуска в разделе Artifacts скачать `mwave-ipa-N` (ZIP; для скачивания нужен вход в GitHub).
4. Распаковать ZIP: внутри `mwave-unsigned.ipa`.

## 2. Подготовить Windows

1. Поставить iTunes и iCloud с сайта Apple (не из Microsoft Store: Sideloadly с версиями из Store не работает).
2. Поставить Sideloadly с https://sideloadly.io
3. Подключить iPhone кабелем, на телефоне нажать «Доверять этому компьютеру».

## 3. Подписать и поставить

1. Запустить Sideloadly, перетащить `mwave-unsigned.ipa` в окно.
2. В поле Apple ID ввести свой Apple ID (лучше отдельный, не основной), нажать Start.
3. Пароль Apple ID Sideloadly спросит в своём окне. Если включена двухфакторная проверка, ввести код с телефона.
4. На iPhone: Настройки → Основные → VPN и управление устройством → профиль с вашим Apple ID → «Доверять».
5. На iOS 16 и новее: Настройки → Конфиденциальность и безопасность → Режим разработчика → включить, телефон перезагрузится.

## 4. Первый запуск: ключ сервера

1. На компьютере получить ключ (нужен SSH-доступ к серверу; ключ не пересылать в открытых чатах):

   ```bash
   ssh saltanovdanil111 "cat /opt/mwave/secret/token"
   ```

2. Передать его на телефон удобным закрытым способом (например, «Заметки» с общим Apple ID или AirDrop на Mac),
   скопировать.
3. В mwave на экране «Ключ сервера» нажать «Вставить», затем «Проверить и сохранить».
   Приложение проверит ключ на сервере и сохранит его в Связке ключей iPhone. Больше ключ не спросит.
4. Сменить ключ можно в Медиатеке: кнопка «Сменить ключ сервера».

## Ограничения бесплатного Apple ID

| Ограничение | Что делать |
|---|---|
| Подпись живёт 7 дней, потом приложение не открывается | Раз в неделю подключить телефон и снова нажать Start в Sideloadly с тем же IPA и тем же Apple ID. Данные (избранное, плейлисты, история, ключ) сохраняются |
| Не больше 3 приложений, подписанных бесплатным Apple ID, на одном телефоне одновременно | Удалить лишние такие приложения или подписать платным аккаунтом разработчика |
| Не больше 10 новых идентификаторов приложений за 7 дней на один Apple ID | Не менять Bundle ID в Sideloadly между переподписями |
| Если удалить приложение, профиль на телефоне (избранное, история) пропадает | Переподписывать поверх, не удаляя |

Платный аккаунт Apple Developer (99 $ в год) снимает ограничение 7 дней (подпись на год) и лимит 3 приложений.
